# 🌾 IA no Agronegócio: o futuro da agricultura

> "A Inteligência Artificial transforma o campo em um espaço mais inteligente, produtivo e sustentável."

## 📚 Sobre o projeto

Este projeto é um quiz educativo desenvolvido para apresentar
como a Inteligência Artificial pode ser utilizada no agronegócio.

O projeto relaciona programação, tecnologia e agricultura,
mostrando algumas aplicações da IA no campo.

## 🚜 Tema

**IA no Agronegócio: o futuro da agricultura**

## 🌱 Assuntos abordados

- Inteligência Artificial
- Agronegócio
- Agricultura
- Produção rural
- Drones
- Sensores
- Solo
- Irrigação
- Clima
- Máquinas agrícolas
- Sustentabilidade
- Tecnologia no campo

## 🎯 Objetivo

O objetivo do projeto é mostrar, de maneira simples e interativa,
como a Inteligência Artificial pode auxiliar os produtores rurais
em diferentes atividades agrícolas.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- JavaScript Modules
